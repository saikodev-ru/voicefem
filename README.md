# DyVocalizer — реалтайм-плагин «феминизации» голоса (VST3, Windows)

## Как это работает (и почему не «чипмунк»)
Обычный pitch-shift сдвигает всё спектр целиком: тембр (форманты) уезжает вместе с высотой, голос звучит «мультяшно».
DyVocalizer использует PSOLA — высота и форманты управляются **независимо**:
- **Pitch** — меняет высоту тона, не трогая тембр.
- **Formant** — отдельно сдвигает форманты (размер «резонатора»), это главное для женского тембра.
- **Согласные и шипящие** (с, ш, ф, дыхание) не обрабатываются грейнами, а проходят напрямую → нет «каши» и металла.

### Движок v2 — что добавлено к живости
- **Стабильный питч-трекер**: медианный фильтр + защита от октавных скачков + гистерезис вокализации — нет «бульканья» и дёрганья высоты.
- **Natural** — коррелированные микро-вариации периода и амплитуды (джиттер/шиммер), как у живого голоса: убирает «стерильность».
- **Двухполосное дыхание**: турбулентный шум 2–7 кГц + низкочастотная «продувка», с медленным дрейфом — воздушность вместо шипения.
- **De-Ess** — сплит-полосный де-эссер (~6.4 кГц): сдерживает шипящие, не трогая остальное.
- **Presence-колокол 3 кГц**, связанный с Air — женское «звучание в маске» без эквалайзерной грязи.
- **Глиссандо формант** (~40 мс) — вращение ручки Formant больше не щёлкает.
- **DC-блоки на входе/выходе** и мягкий потолок-лимитер — чистый сигнал без артефактов клиппинга.

## Параметры
| Параметр | Что делает |
|---|---|
| Pitch Mode | Shift — фиксированный сдвиг; Target — автоподстройка вашей средней высоты к Target Hz |
| Pitch (st) | сдвиг в полутонах (Shift) |
| Target Hz | желаемая средняя высота (Target), у женской речи обычно 180–230 Гц |
| Formant (st) | сдвиг формант; +2…+4 типично |
| Intonation | 0 — монотонно, 1 — как у вас, >1 — выразительнее |
| Breath | воздушность на звонких звуках |
| Body | низкий шельф 250 Гц (минус — меньше «грудного» гула) |
| Air | высокий шельф 5 кГц + presence 3 кГц (плюс — светлее и звонче) |
| Natural | живость: микро-вариации периода/амплитуды голоса (0 — стерильно, 1 — очень живо) |
| De-Ess | сдерживание шипящих с–ш после обработки |
| Voicing Thr | порог детектора высоты; поднимите, если на шипящих слышны артефакты, опустите, если тихие гласные «пропадают» |
| Voice Range | нижняя граница вашего голоса; задаёт задержку (Deep ~34 мс, Standard ~32 мс, Higher ~26 мс при 48 кГц) |
| Mix / Output | сухой/мокрый и громкость |

Пресеты — в выпадающем списке плагина и в меню пресетов FL Studio.

## Задержка
Плагин сообщает хосту latency (DSP-движок ≈ 26–34 мс при 48 кГц; нейро-движок — по пресету AI Quality: Fast ≈ 80 мс, Smooth ≈ 160 мс, Max ≈ 260 мс). При записи FL компенсирует её сам.
Для живого мониторинга лучше мониторить обработанный сигнал с ASIO-буфером 128–256 сэмплов.

## Нейро-движок (режим Neural) — основной
Помимо DSP/PSOLA-движка плагин содержит **нейросетевую конвертацию голоса** (как в Supertone Shift): контент-энкодер (класс ContentVec) → конверсия F0 → RVC-генератор. Голос пересинтезируется тембром выбранной модели — полная смена тембра, а не сдвиг формант. С версии 0.4.0 **Neural — движок по умолчанию**.

### Стриминг v2 (без «покадровости»)
- **Overlap-render**: каждый шаг рендерит chunk+overlap кадров; первые overlap кадров перекрывают хвост предыдущего шага и сшиваются линейным кроссфейдом — стыков не слышно.
- **Позиционный кэш F0**: высота анализируется один раз на абсолютную позицию — перекрывающиеся окна видят одинаковый питч (раньше state-детектор выдавал разные значения одним и тем же кадрам в разных окнах).
- **Паузы = тишина**: неозвученным кадрам подаётся 0 Гц (как при обучении RVC) вместо «замороженного» питча — больше нет гула в паузах; одиночные выпадения интерполируются.
- **Блочный API**: ни одной аллокации на сэмпл (в v0.3.2 было ~100 000/сек), все буферы преаллоцированы.
- **Саморегулирующаяся очередь вывода**: без кольцевого буфера, дрейф-коррекций и щелчков; недогруз CPU даёт короткий фейд в ноль, а не разрыв.

### Пресеты AI Quality (латентность/качество)
| Пресет | Латентность | Стык каждые | Кроссфейд | CPU |
|---|---|---|---|---|
| Fast | ~80 мс | 40 мс | 20 мс | самый высокий |
| Smooth (по умолчанию) | ~160 мс | 80 мс | 40 мс | средний |
| Max | ~260 мс | 160 мс | 60 мс | самый низкий |

Важно: **ниже латентность — выше нагрузка на CPU** (инференс запускается чаще). Если звук заикается — выберите Smooth или Max. Смена пресета перезапускает нейро-поток (короткий фейд).

### Установка моделей
Модели кладутся в `%APPDATA%\DyVocalizer\models` (кнопка **Models...** в интерфейсе открывает эту папку). Нужны два типа файлов:

- `content.onnx` — контент-энкодер ContentVec-768 (общий для всех голосов);
- `voice_<имя>.onnx` — один или несколько RVC-генераторов.

**Способ 1 — готовый скрипт (проще всего):**
```
powershell -ExecutionPolicy Bypass -File tools\install_models.ps1
```
Скачает ContentVec-энкодер, базовый голос HuTao (зашит как стандартная библиотека) и готовые женские голоса (HuggingFace).

**Способ 2 — Release:** в GitHub Releases лежит `DyVocalizer-models.zip` (content.onnx + базовый голос HuTao) — распаковать в `%APPDATA%\DyVocalizer\models`.

**Способ 3 — артефакт CI:** Actions → прогон → артефакт `DyVocalizer-models` → распаковать в `%APPDATA%\DyVocalizer\models`.

**Способ 4 — свои голоса из RVC-чекпойнтов (.pth):**
```
pip install torch onnx onnxruntime scipy
# Windows/CPU torch:  pip install torch --index-url https://download.pytorch.org/whl/cpu
python tools\pth_to_onnx.py Модель.pth voice_имя.onnx
copy voice_имя.onnx "%APPDATA%\DyVocalizer\models\"
```
Поддерживаются RVC v1 (256) и v2 (768), с F0 и без. Конвертер повторяет официальный экспорт RVC (`SynthesizerTrnMsNSFsidM`) и автоматически выбирает нужный режим кадров. Также подходят готовые ONNX-экспорты в конвенции w-okada / VC Client (phone/phone_lengths/pitch/pitchf/ds[/rnd]).

Проверка совместимости: `python tools/validate_model.py "%APPDATA%\DyVocalizer\models"`

В плагине: Engine = **Neural (model)** (по умолчанию), выберите голос в списке Neural Voice, при необходимости смените AI Quality. Пока модели не найдены/грузятся, звучит DSP-движок, а строка статуса показывает, что происходит:
- `no models in <путь>` — папка пуста (путь указан точно; файлы можно докладывать на ходу, движок подхватит через ~2 с);
- `content.onnx: ...` / `voice model: ...` — модель не загрузилась, причина от ONNX Runtime;
- `ready: <голос>` — нейро-режим активен.

Модели RVC берите только **со своего голоса / с согласия владельца** — плагин для личного использования.

### Замечания
- В режиме Neural параметры Pitch/Target/Intonation работают (управляют F0), Breath/Body/Air/De-Ess действуют как пост-обработка; Formant не используется (тембр задаёт модель).
- Первый переключение в Neural грузит модели (секунды) — в этот момент звучит DSP-движок.
- Если моделей нет или они несовместимы — плагин остаётся на DSP-движке и пишет статус в интерфейсе.
- Отключить нейро-часть при сборке: `cmake -B build -DDYV_NEURAL=OFF`.

## Сборка
### Вариант А — GitHub (без установки компилятора)
1. Создайте репозиторий, загрузите в него всё содержимое этой папки (включая `.github`).
2. Вкладка **Actions → Build VST3 (Windows) → Run workflow**.
3. Скачайте артефакт `DyVocalizer-VST3`.

### Вариант Б — локально (Visual Studio 2022 + CMake)
```
cmake -B build -G "Visual Studio 17 2022" -A x64
cmake --build build --config Release
```
Результат: `build/DyVocalizer_artefacts/Release/VST3/DyVocalizer.vst3`

## Установка в FL Studio 26
1. Скачайте артефакт `DyVocalizer-VST3` из Actions (зелёный прогон) и распакуйте ZIP.
2. Скопируйте **всю папку** `DyVocalizer.vst3` (внутри должны быть `Contents\x86_64-win\DyVocalizer.vst3`, `moduleinfo.json` и **`onnxruntime.dll`**) в `C:\Program Files\Common Files\VST3\`
   - Если рядом с `Contents\x86_64-win\DyVocalizer.vst3` нет `onnxruntime.dll` — Neural-режим не запустится, а в старых сборках плагин мог вообще не открыться.
3. FL Studio → Options → Manage plugins → **Find installed plugins**
4. Поставьте DyVocalizer на вход микрофона в Mixer (Fast Track Input → слот эффекта).

### Если FL пишет «There was a problem opening the plugin»
- Убедитесь, что установлена папка `DyVocalizer.vst3` целиком (не отдельные файлы) и `onnxruntime.dll` лежит в `Contents\x86_64-win\` рядом с самим плагином.
- Свежие сборки грузят ORT через delay-load из папки плагина — если dll отсутствует, плагин всё равно откроется (Neural-режим просто будет недоступен, движок останется DSP).
- Удалите старую копию из `C:\Program Files\Common Files\VST3\` перед заменой, затем пересканируйте плагин.

## Советы по настройке
- Начните с «Feminine - Standard», затем крутите Formant: если голос звучит «маленьким/писклявым» — уменьшите; если «мужским в маске» — увеличьте.
- Для глубокого превращения возьмите «Feminine - Deep Transform»: Target 210 Гц + Formant +3.2 + Body −4 дБ.
- Если звук «булькает» — поднимите Voicing Thr или поставьте Voice Range ближе к вашему голосу.
- Слишком «роботизированно» — поднимите Natural до 0.6–0.8; слишком «шероховато» — опустите до 0.2–0.3.
- Шипящие «свистят» после Air — добавьте De-Ess (0.4–0.6).
- Говорите ближе к микрофону и без сильного шума в комнате: детектор высоты чувствителен к фону.
- Тест движка (без JUCE): `g++ -O2 -std=c++17 test/engine_test.cpp -o t && ./t`
