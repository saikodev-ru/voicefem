# VoiceFem — реалтайм-плагин «феминизации» голоса (VST3, Windows)

## Как это работает (и почему не «чипмунк»)
Обычный pitch-shift сдвигает всё спектр целиком: тембр (форманты) уезжает вместе с высотой, голос звучит «мультяшно».
VoiceFem использует PSOLA — высота и форманты управляются **независимо**:
- **Pitch** — меняет высоту тона, не трогая тембр.
- **Formant** — отдельно сдвигает форманты (размер «резонатора»), это главное для женского тембра.
- **Согласные и шипящие** (с, ш, ф, дыхание) не обрабатываются грейнами, а проходят напрямую → нет «каши» и металла.

## Параметры
| Параметр | Что делает |
|---|---|
| Pitch Mode | Shift — фиксированный сдвиг; Target — автоподстройка вашей средней высоты к Target Hz |
| Pitch (st) | сдвиг в полутонах (Shift) |
| Target Hz | желаемая средняя высота (Target), у женской речи обычно 180–230 Гц |
| Formant (st) | сдвиг формант; +2…+4 типично |
| Intonation | 0 — монотонно, 1 — как у вас, >1 — выразительнее |
| Breath | воздушность на звонких звуках |
| Body | низкий шельф 250 Гц (минус — меньше «грудного» гула) |
| Air | высокий шельф 5 кГц (плюс — светлее) |
| Voicing Thr | порог детектора высоты; поднимите, если на шипящих слышны артефакты, опустите, если тихие гласные «пропадают» |
| Voice Range | нижняя граница вашего голоса; задаёт задержку (Deep ~34 мс, Standard ~32 мс, Higher ~26 мс при 48 кГц) |
| Mix / Output | сухой/мокрый и громкость |

Пресеты — в выпадающем списке плагина и в меню пресетов FL Studio.

## Задержка
Плагин сообщает хосту latency (≈ 26–34 мс при 48 кГц). При записи FL компенсирует её сам.
Для живого мониторинга лучше мониторить обработанный сигнал с ASIO-буфером 128–256 сэмплов.

## Сборка
### Вариант А — GitHub (без установки компилятора)
1. Создайте репозиторий, загрузите в него всё содержимое этой папки (включая `.github`).
2. Вкладка **Actions → Build VST3 (Windows) → Run workflow**.
3. Скачайте артефакт `VoiceFem-VST3`.

### Вариант Б — локально (Visual Studio 2022 + CMake)
```
cmake -B build -G "Visual Studio 17 2022" -A x64
cmake --build build --config Release
```
Результат: `build/VoiceFem_artefacts/Release/VST3/VoiceFem.vst3`

## Установка в FL Studio 26
1. Скопируйте `VoiceFem.vst3` в `C:\Program Files\Common Files\VST3\`
2. FL Studio → Options → Manage plugins → **Find installed plugins**
3. Поставьте VoiceFem на вход микрофона в Mixer (Fast Track Input → слот эффекта).

## Советы по настройке
- Начните с «Feminine - Standard», затем крутите Formant: если голос звучит «маленьким/писклявым» — уменьшите; если «мужским в маске» — увеличьте.
- Если звук «булькает» — поднимите Voicing Thr или поставьте Voice Range ближе к вашему голосу.
- Говорите ближе к микрофону и без сильного шума в комнате: детектор высоты чувствителен к фону.
- Тест движка (без JUCE): `g++ -O2 -std=c++17 test/engine_test.cpp -o t && ./t`
